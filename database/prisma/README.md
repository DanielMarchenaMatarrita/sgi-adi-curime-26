# Prisma — ubicación futura del esquema

`database/prisma/schema.prisma` será única ubicación autoritativa del esquema Prisma cuando modelo relacional V2 quede congelado y autorizado.

No crear todavía `schema.prisma`, migraciones ni configuración ejecutable: relaciones, constraints y modelo físico siguen en consolidación. Ver [freeze gates](../docs/target-v2/freeze-gates.md).
