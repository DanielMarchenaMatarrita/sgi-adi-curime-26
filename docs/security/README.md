# Seguridad y privacidad

- V1.1: `Person` identidad física, `User` acceso y `Role`/`Permission` autorización; no equivalen.
- DOC-VAL-04: documento `PUBLIC`, `INTERNAL` o `RESTRICTED` más permisos RBAC, alcance funcional y cargo institucional verificable.
- Controles también en backend y almacenamiento. Ocultar botones del frontend no protege un recurso.
- Archivos de respaldo, datos fiscales y correspondencia personal deben tratarse según autorización contextual y política de conservación.
- No almacenar secretos, identificaciones reales ni tokens dentro del repositorio Git.
