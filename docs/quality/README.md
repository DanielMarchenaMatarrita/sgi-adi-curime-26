# Calidad y verificación

Antes del primer despliegue definir: convenciones CI, validación de Prisma, integridad de migraciones, pruebas de relaciones, roles y acceso documental, idempotencia de movimientos, conciliación financiera y validación de diagramas Mermaid. Documentar la evidencia real y el alcance; no atribuir pruebas no ejecutadas.
