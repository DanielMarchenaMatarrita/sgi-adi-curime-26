# 9.3C — Recepciones en especie, préstamos, devoluciones y pérdidas

**Estado:** INV-VAL-04/05 y DON-INV-VAL-01 confirmadas funcionalmente.

## D-9.3C-01 — Submodelo conceptual de préstamos

```mermaid
erDiagram
    InventoryItem ||--o{ InventoryLoan : presta
    InventoryLoan ||--o{ InventoryLoanCheckoutAllocation : salida
    InventoryLoan ||--o{ InventoryLoanReturn : recepciones
    InventoryLoan ||--o{ InventoryLoanShortage : faltantes
    InventoryStockLot o|--o{ InventoryLoanCheckoutAllocation : lote
    InventoryUnit o|--o{ InventoryLoanCheckoutAllocation : unidad
    InventoryLoanReturn ||--|{ InventoryLoanReturnDetail : detalla
    InventoryLoanCheckoutAllocation ||--o{ InventoryLoanReturnDetail : devuelve
    InventoryLoanCheckoutAllocation ||--o{ InventoryLoanShortage : faltante
    InventoryLoanShortage ||--o{ InventoryLoanShortageDecision : decisiones
    BoardResolution o|--o{ InventoryLoanShortageDecision : respalda_si_aplica
    InventoryMovement o|--o| InventoryLoanReturnDetail : recupera_disponibilidad
```

**Invariantes:** un préstamo se asocia a un único `InventoryItem`; se permite entrega por varios lotes/unidades, múltiples recepciones y condiciones diferentes. Un faltante no es una devolución física; su resolución competente permite cierre administrativo sin incrementar `currentQuantity`.

## D-9.3C-02 — Ecuación de conciliación

```mermaid
flowchart LR
    A["Cantidad prestada"] --> B["Devuelta físicamente"]
    A --> C["Faltante resuelto"]
    A --> D["Pendiente"]
    B --> E{"¿Apta para uso?"}
    E -->|Sí| F["Recuperar disponibilidad"]
    E -->|No| G["Custodia restringida"]
    C --> H["Cierre administrativo sin entrada física"]
```

`Prestada = Devuelta físicamente + Faltante resuelto + Pendiente` (cantidades disjuntas). La pérdida de una unidad ya descontada al prestar no genera otra salida de disponibilidad.

## D-9.3C-03 — Donación física y stock disponible

```mermaid
flowchart TD
    A["InKindDonation aceptada"] --> B["InKindDonationReceipt"]
    B --> C["InKindDonationReceiptLine verificada"]
    C --> D{"¿Seguimiento?"}
    D -->|Lote| E["InventoryStockLot"]
    D -->|Unidad| F["InventoryUnit"]
    E --> G{"¿Apta para disponibilidad?"}
    F --> G
    G -->|Sí| H["InventoryMovement ENTRY positivo"]
    G -->|No| I["Existencia bajo custodia restringida"]
    H --> J["InventoryItem.currentQuantity"]
```

**Invariantes:** oferta ≠ entrega; se registra todo bien aceptado bajo custodia desde la recepción, incluso si está dañado; solo cantidad habilitada modifica disponibilidad; ni recepción ni valoración patrimonial crean automáticamente `FinancialMovement` de ingreso monetario.
