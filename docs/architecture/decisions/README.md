# Registro de decisiones

Los ADR documentan decisiones técnicas con contexto, alternativas y consecuencias. Las decisiones institucionales y funcionales (DOC-VAL, FIN-MNT-VAL, INV-VAL, etc.) se registran primero en el [registro de decisiones](decision-register.md).

No confundir un ADR aprobado con una funcionalidad implementada o validada.
